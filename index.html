MICRO ROBOT PROJECT

라인 마이크로 로봇 제작하기

Z80 원보드 컴퓨터, DC 모터 제어회로, 센서 신호 검출회로, 프레임 제작과 제어 프로그램을 차례로 완성해 라인 트레이싱 마이크로 로봇을 만드는 프로젝트 지도서입니다.

Z80모터 제어센서라인 트레이서

00과정 개요

Z80 원보드 컴퓨터, DC 모터 제어회로, 센서 신호 검출회로, 프레임 제작과 제어 프로그램을 차례로 완성해 라인 트레이싱 마이크로 로봇을 만드는 프로젝트 지도서입니다.

직종은 전기계측제어, 소요시간은 이론 80시간·실기 200시간입니다. 각 과제는 관련지식 학습 → 작업도면 → 기능(동작) 설명 → 기술·기능 학습활동 → 작업계획 → 실습결과 보고 → 평가 순서로 진행합니다.

이 사이트는 1999년 대한상공회의소 직업교육훈련사업단 프로젝트지도서 99-36 「라인 마이크로 로봇 제작하기」(집필 정병우, 검토 안상채)의 한글 97 원고를 웹 문서로 옮긴 것입니다.

03학습 방법

각 장의 관련 이론을 읽고 절 끝의 연습문제에 답한 뒤, 작업도면과 작업계획서에 따라 회로를 제작합니다. 제작 후에는 실습결과보고서를 작성하고 평가표로 스스로 점검합니다.

원본 한글 파일과 회로도(OrCAD), 발표 자료는 제10장에서 내려받을 수 있습니다.
